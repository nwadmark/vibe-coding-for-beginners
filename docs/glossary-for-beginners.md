# Glossary for Beginners

See a word you don't understand? Look here first. No question is too basic.

---

### Repository (repo)

A folder where all the workshop files live. This entire project — the guides, the prompts, the code examples — is one repository. When someone says "the repo," they mean this collection of files.

### Branch

A separate copy of the files where changes can be made safely. Think of it like making a copy of a Google Doc so you can edit it without messing up the original. When the changes look good, they get merged back in.

### Clone

Download a copy of the repository to your computer. You don't need to do this if you use Replit — Replit runs everything in your browser. Cloning is only relevant if you use Cursor or another local editor.

### Fork

Make your own personal copy of someone else's repository. It's like "Save As" for an entire project. You get your own version that you can change however you want without affecting the original.

### Merge

Combine changes from one branch into another. When someone finishes editing their copy, they merge it back into the main version. You won't need to do this during the workshop.

### Terminal / Command Line

A text-based way to control your computer by typing commands instead of clicking buttons. **You won't need this if you use the browser path** (Claude.ai + Replit). The browser path was designed specifically so you never have to open a terminal.

### Directory

A folder on your computer. When documentation says "the `build/` directory," it just means the folder called `build`. Same thing, different word.

### File Path

The location of a file, like a street address for your computer. `workshop/pre-work.md` means "inside the `workshop` folder, the file called `pre-work.md`." The slashes separate folder names, and the last part is the actual file.

### Python

The programming language the workshop uses. The AI writes it for you — you don't need to learn it. Python was chosen because it reads close to plain English and is the most popular language for the kind of tools PMs build.

### Code Editor

The application where you write and see code. Replit is the code editor we recommend for beginners — it runs in your browser. Cursor is another option that runs on your computer. Think of it like Microsoft Word, but for code instead of documents.

### Console / Output

The area where you see results when code runs. In Replit, it's the bottom panel. When your program prints something (like a score or a recommendation), it shows up here. When the program asks you a question, you click in the console and type your answer.

### Error Message

When code doesn't work, it tells you why in red text. **This is not your fault — it's a normal part of the process.** Even professional developers see error messages every day. When you see one, copy the red text, paste it into Claude or ChatGPT, and say "fix this error." That's the standard workflow.

### Debug

Fix errors in code. Everyone does this — it's not a sign that something went wrong. It's a normal step in building anything. In this workshop, debugging means copying the error message into your AI assistant and asking it to fix the problem.

### Syntax

The grammar rules of a programming language. Just like English has rules about where commas and periods go, Python has rules about spacing and punctuation. **The AI handles syntax for you.** If you see a "SyntaxError," it usually means the code didn't copy-paste cleanly — just paste it again.

### Prompt

The plain-English description you type into Claude or ChatGPT. "Build me a tool that scores features on four criteria" is a prompt. The better your prompt (clearer, more specific), the better the code the AI writes. This is the main skill you'll practice in the workshop.

### Run

Execute the code — make it actually do something. In Replit, you click the green **Run** button. The code goes from text sitting in the editor to a program that asks you questions and shows you results.

### Library / Module

Pre-built code that someone else already wrote. When the workshop says "Python built-ins only," it means the AI should use tools that come pre-installed with Python — no extra downloads needed. You don't need to think about this; it's a constraint in the prompts that keeps things simple.
