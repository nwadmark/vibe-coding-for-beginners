# I'm Stuck — Now What?

**First: Take a breath.** Getting stuck is not failing. It's part of the process. Every person who's ever learned to code has been exactly where you are right now.

---

## Quick Diagnosis

**What's not working?** Click the one that matches:

### 1. I can't sign up for Claude/ChatGPT/Replit

Go to [setup/browser-path.md](../setup/browser-path.md) and check the troubleshooting table at the bottom.

Common fixes:
- Try a different browser (Chrome works best)
- Check your internet connection
- Try incognito/private mode
- Use a different email address

Still stuck? [Email or Discord link when you have one]

---

### 2. My code has an error message

**This is the #1 most common thing. You're in good company.**

DO THIS:
1. Read the error message (it's trying to help!)
2. Copy the ENTIRE error (all the red text)
3. Paste it into Claude or ChatGPT
4. Say: "I got this error. Please fix it and explain what went wrong."
5. Copy the fixed code
6. Replace your old code with the new code
7. Click Run again

DON'T DO THIS:
- Panic
- Assume you broke something permanently
- Start over from scratch (the fix is usually small)
- Feel bad (professional developers see errors constantly)

**Pro tip**: Errors are not failures. They're the computer telling you exactly what's wrong. That's helpful!

---

### 3. I don't understand what the code does

**That's okay. You don't need to understand every line.**

But if you're curious:
1. Copy the code
2. Paste into Claude or ChatGPT
3. Say: "Explain this code to me like I'm not a programmer. What does each section do in plain English?"

If the explanation is still confusing:
- Check [docs/glossary-for-beginners.md](glossary-for-beginners.md) for terms
- Ask AI: "Explain that more simply"

**Remember**: Understanding is bonus. Making it work is the goal.

---

### 4. The tool runs but doesn't do what I expected

This happens! Code does exactly what you tell it, which might not be what you meant.

DO THIS:
1. Describe what you WANTED to happen
2. Describe what ACTUALLY happened
3. Paste both into Claude/ChatGPT with your code
4. Say: "This isn't doing what I wanted. Please fix it."

The AI will adjust the logic and explain why it was doing something different.
