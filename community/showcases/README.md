# Community Showcases

See what others have built with vibe coding. Each showcase is a short write-up of a tool a PM built, why they built it, and what they learned.

---

## How to Submit Your Build

1. Copy the [TEMPLATE.md](TEMPLATE.md) file
2. Fill in each section with your tool's details
3. Submit a pull request adding your file to this folder, named `your-tool-name.md`

All experience levels are welcome. Whether you built a simple scoring tool or a full data pipeline, we want to see it.
