# Prompts for Debugging

Use these prompts when your code throws an error, produces wrong output, or behaves unexpectedly. Each prompt is designed for a specific type of problem.

**Important:** Always paste these in the **same conversation** where you generated the code. The AI already knows what the code is supposed to do.

---

## Fix an Error Message

The most common debugging scenario. Your code crashes with a traceback.

```
My code is broken. Here's the error:

[Paste the full error message here]

Here's the code that caused it:

[Paste the relevant code — or the whole file if it's short]

Fix the error. Explain what went wrong in one sentence.
Do not change any other logic — only fix this specific issue.
```

**Tip:** Always paste the **full** error message, including the traceback. "It doesn't work" gives the AI nothing. `TypeError: unsupported operand type(s) for +: 'int' and 'str'` tells it exactly what to fix.

---

## Fix Wrong Output

The code runs without errors, but the numbers or text are wrong.

```
The code runs, but the output is wrong.

I expected:
[Describe or paste what you expected to see]

I got:
[Paste the actual output]

Here's the code:
[Paste the relevant section]

Find the bug. Fix it. Explain what was wrong.
Do not change the output format — only fix the calculation or logic.
```

**When to use:** Score calculations that seem off, sorting that goes the wrong direction, labels that don't match values. The expected vs actual comparison is key — it narrows the AI's search.

---

## Fix an Indentation or Syntax Error

Common when copying code between tools or when the AI generates code with mixed tabs and spaces.

```
I'm getting this error when I run my Python code:

[Paste the error — usually IndentationError or SyntaxError]

The code was generated by an AI assistant. It's likely a copy-paste issue.
Fix the indentation and syntax errors throughout the entire file.
Do not change any logic — only fix formatting issues.

Here's the code:
[Paste the full file]
```

**When to use:** After copying from Claude/ChatGPT into Replit or Cursor. Indentation errors are the most common problem with copy-paste.

---

## Fix Input Handling

The code crashes when the user types something unexpected.

```
My tool crashes when I enter [describe what you typed].

Here's the error:
[Paste the error]

The tool should handle bad input gracefully:
- If the user enters text when a number is expected, show "Please enter a number" and ask again
- If the user enters a number outside the valid range, show the valid range and ask again
- Never crash — always recover and re-prompt

Fix the input handling. Keep all other logic the same.
```

**When to use:** When typing a letter instead of a number crashes the tool, when entering 0 or 11 on a 1-10 scale causes problems, or when pressing Enter without typing anything breaks the flow.

---

## Fix a Feature That Disappeared

The AI rewrote your code and accidentally removed something that was working before.

```
After your last change, these features stopped working:
1. [First missing feature]
2. [Second missing feature]

Add them back. Here's the current code:
[Paste the current code]

Do not remove anything else. Only add back the missing features.
```

**When to use:** After Prompt #2 or #3 when the AI rewrites too much. Common symptoms: risk flag is gone, PM action suggestions disappeared, bar chart is missing.

---

## Fix File Reading Issues

The tool can't find or read a data file.

```
My tool can't read the data file. I get this error:

[Paste the error — usually FileNotFoundError]

The file is called [filename] and it's in the same folder as the Python script.
The file format is:
[Describe the format — CSV columns, text file structure, etc.]

Fix the file reading code. Make sure it:
- Looks in the same directory as the script
- Handles the case where the file doesn't exist (show a helpful message instead of crashing)
- Reads the correct format

Keep all other logic the same.
```

**When to use:** Cohort analyzer, feedback analyzer, or metric dashboard — any tool that reads from a CSV or text file.

---

## "It Just Doesn't Work" — Last Resort

When you have no idea what's wrong. Use this only when the more specific prompts above don't apply.

```
This code is not working and I'm not sure why.

Here's what the tool is supposed to do:
[Describe the expected behavior in 2-3 sentences]

Here's what actually happens when I run it:
[Describe what you see — or paste the output]

Here's the full code:
[Paste the entire file]

Find every issue and fix them. List each fix you made and why.
```

**When to use:** As a last resort. This prompt is less targeted, so the AI might change more than necessary. If it over-corrects, follow up with: "You changed [thing I didn't want changed]. Revert that specific change."

---

## Debugging Tips

- **One problem per prompt.** Fix the crash first, then fix the formatting, then fix the logic. Don't ask the AI to fix everything at once.
- **Paste the full error.** The traceback tells the AI exactly which line broke and why.
- **"Do not change any other logic"** is your safety net. Always include it.
- **If the fix breaks something else,** say: "Your fix for [problem A] broke [feature B]. Fix A without breaking B."
- **If you're stuck in a loop** of the AI breaking and fixing things, start fresh: copy the last version that worked, open a new conversation, and paste the working code plus one targeted prompt.
