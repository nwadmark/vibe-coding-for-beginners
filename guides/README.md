# Tool Guides

Reference guides for every tool used in this workshop. Choose the tools that work for you — there is no single "right" setup, and you can switch or combine tools at any time.

## Quick Decision Guide

```
Are you a complete beginner?
  └─ Yes → Claude + Replit
       Best starting combo. No installation, PM-friendly output.

Do you want local development?
  └─ Yes → Claude + Cursor
       Files on your computer, professional IDE, AI built in.

Do you need unlimited messages?
  └─ Yes → ChatGPT + Replit
       ChatGPT free tier has no message caps.

Building web prototypes fast?
  └─ Yes → Lovable (paid, $20/mo)
       Full-stack apps from plain English. Deployed instantly.
```

## You Can Use Multiple Tools

Most participants end up using 2-3 tools together. Common combinations:

- **Claude + Replit** — Claude generates the code, Replit runs it. Best for workshop and learning.
- **ChatGPT + Replit** — Same workflow with unlimited ChatGPT messages. Good for rapid iteration.
- **Claude + Cursor** — Claude for complex prompts, Cursor for quick inline edits. Best for ongoing tool development.
- **Any AI + Lovable** — Use Claude or ChatGPT to figure out the logic, then use Lovable for a polished prototype when you need to show stakeholders.

You do not need to pick one and stick with it. Experiment and find what works for your workflow.
