# Lovable Guide

> **Advanced / Paid Tool** — Lovable costs $20/month. It is not required for this workshop. This guide is for participants who want to explore more powerful prototyping tools after completing the core material.

---

## What Lovable Is

Lovable is an AI-powered web app builder. You describe what you want in plain English, and Lovable generates a full-stack web application — frontend, backend, database, and deployment — in minutes.

- **Generates full-stack applications.** Not just code snippets — complete, deployed web apps.
- **Visual preview as you build.** See the app update in real-time as you describe changes.
- **Production-ready output.** The generated apps use modern frameworks (React, Supabase) and can be shared via URL immediately.
- **Costs $20/month.** There is a limited free trial, but meaningful use requires the paid tier.

---

## When PMs Use Lovable

- **Need a clickable prototype today.** You have a meeting tomorrow and need something stakeholders can interact with.
- **User testing this week.** You want real users clicking through a realistic interface, not looking at wireframes.
- **Stakeholder demo.** You need to show — not just describe — what a feature would look like.
- **Want production-quality UI without design.** Lovable generates polished interfaces that look professional without any design skills.

## How It Is Different from Vibe Coding

| Aspect | Vibe Coding (Workshop) | Lovable |
|---|---|---|
| What you write | Prompts → AI generates Python scripts | Prompts → AI generates full web apps |
| What you get | Command-line tools you run locally | Deployed web apps with URLs |
| Learning | High — you see the code, understand the logic | Lower — the code is abstracted away |
| Flexibility | Total — you control every line | Moderate — you control via prompts |
| Speed | 15-60 min per tool | 5-30 min per app |
| Cost | Free | $20/month |
| Best for | Learning, internal tools, data analysis | User testing, stakeholder demos, prototypes |

**Key difference:** Vibe coding teaches you how things work. Lovable does things for you. Both are valuable — they serve different purposes.

## Example PM Use Case

**The situation:** Alex, PM at ShopFlow, needs to test a new inventory dashboard concept with 5 warehouse managers. The next user research session is in 3 days.

**What Alex did:**

1. Described the dashboard to Lovable: "Build an inventory management dashboard with a table showing product name, SKU, quantity, and status. Add filters for status (in stock, low, out of stock). Add a form to update quantities. Use a clean, professional design."

2. Lovable generated a working web app in 20 minutes — table, filters, form, and a mock database.

3. Alex refined it with follow-up prompts: "Add a low-stock alert banner at the top showing how many items are below threshold."

4. Shared the URL with the 5 warehouse managers for testing.

5. Collected feedback, learned that managers wanted bulk editing (select multiple items, update at once), and iterated.

**Total time:** About 90 minutes from idea to user-tested prototype.

## When to Use Lovable vs Vibe Coding

| Use Case | Vibe Coding | Lovable |
|---|---|---|
| Learning how tools work | Best | Not ideal |
| Internal data analysis scripts | Best | Overkill |
| Command-line PM tools | Best | Not applicable |
| Clickable prototype for user testing | Possible (Streamlit) | Best |
| Stakeholder demo with polished UI | Difficult | Best |
| Quick proof-of-concept | Good | Good |
| Understanding the code you built | Yes | Limited |

**They complement each other.** Use vibe coding to understand the logic and build internal tools. Use Lovable when you need a polished, shareable prototype fast.

## How It Complements This Workshop

1. **The workshop teaches you fundamentals.** You learn how to describe tools precisely, iterate on output, and think about inputs/outputs/logic. These skills apply directly to Lovable prompts.

2. **Lovable is the "production upgrade."** When a command-line tool proves the concept and you need a shareable version, Lovable can build the web app.

3. **Better prompts from workshop skills.** Participants who understand vibe coding write better Lovable prompts. You know to specify the data format, the output layout, and the edge cases — because the workshop taught you that.

## Getting Started

1. Go to [lovable.dev](https://lovable.dev)
2. Sign up and choose a plan ($20/month for the standard tier)
3. Start with a template or a blank project
4. Describe what you want in the prompt box
5. Watch it build in real-time
6. Refine with follow-up prompts
7. Share the generated URL with your team or test users

**Tip:** Start by describing something simple — a single-page dashboard or a form with a table. Add complexity incrementally, just like the workshop loop.
