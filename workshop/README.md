# Workshop

A 60-75 minute hands-on session where product managers build a real PM Decision Framework tool using free AI coding assistants. No coding experience required — participants write prompts, the AI writes the code, and everyone walks out with a working tool they built themselves.

---

## Agenda at a Glance

| Time | Section | What Happens |
|---|---|---|
| 00:00–00:05 | Hook | Live demo of the finished tool |
| 00:05–00:15 | Orientation | What is vibe coding, why PMs, how today works |
| 00:15–00:25 | Loop 1: Generate | Paste Prompt #1, get working code, run it |
| 00:25–00:40 | Loop 2: Improve | Paste Prompt #2, add visual bars and labels |
| 00:40–00:50 | Loop 3: Customize | Choose Prompt #3A/B/C, make the tool yours |
| 00:50–01:00 | Ship + Reflect | Share your work, reflection questions |
| 01:00–01:10 | Next Steps + Q&A | What to build next, resources, open questions |

## What Should I Do Next?

| I'm a Facilitator | I'm a Participant |
|---|---|
| 1. Read the [facilitator guide](facilitator-guide.md) end to end | 1. Complete the [pre-work](pre-work.md) (15 minutes) |
| 2. Do a dry run of the build yourself | 2. Make sure your AI assistant and coding environment are working |
| 3. Set up your demo environment (see facilitator guide) | 3. Run `python setup/verify-setup.py` to verify your setup |
| 4. Send the pre-work link to participants 1 week before | 4. Show up with your laptop charged and ready |
| 5. Print or share the [participant guide](participant-guide.md) | 5. Open the [participant guide](participant-guide.md) when the session starts |
